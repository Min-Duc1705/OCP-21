# OCP Java 21 Quiz App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng ứng dụng web standalone hiện đại (không cần node_modules) để ôn tập trắc nghiệm OCP Java SE 21 từ 7 chương file markdown, hỗ trợ chế độ Luyện tập theo chương và Chế độ Thi thử tính giờ.

**Architecture:** Sử dụng script Node.js `parser.js` để tự động bóc tách 7 file markdown thành `quiz-data.js`. Xây dựng ứng dụng Single Page Web App bằng HTML5, CSS hiện đại (Glassmorphism, Dark/Light mode) và Vanilla JS chia module (`storage.js`, `app.js`). Tích hợp `Prism.js` để highlight code Java offline.

**Tech Stack:** HTML5, Modern CSS (CSS Variables, Flexbox/Grid, Glassmorphism), Vanilla JavaScript (ES6+), Node.js (dùng cho parser trích xuất dữ liệu), Prism.js (Syntax Highlighting).

**Spec:** [docs/superpowers/specs/2026-10-05-ocp21-quiz-app-design.md](file:///t:/University/Interview/Java/ocp-21-study-guide/docs/superpowers/specs/2026-10-05-ocp21-quiz-app-design.md)

## Global Constraints

- Không cài đặt hay tạo thư mục `node_modules` trong ứng dụng frontend; ứng dụng phải mở và chạy được trực tiếp bằng trình duyệt.
- Dữ liệu câu hỏi phải trích xuất chính xác 100% từ 7 file `*-review-questions.md` bao gồm mã code Java, các lựa chọn A..G, đáp án đúng và phần giải thích chuyên sâu.
- Lưu trữ toàn bộ tiến độ, câu đánh dấu (bookmark), câu làm sai (mistakes), và lịch sử thi vào `localStorage`.
- Giao diện phải đẹp mắt, trực quan, hỗ trợ Dark Mode mặc định và có thể chuyển sang Light Mode.

## Review Focus

- Xử lý câu hỏi có nhiều dòng code Java hoặc code chứa ký tự đặc biệt `<`, `>`, `&`, `$` không bị lỗi hiển thị HTML.
- Nhận diện chính xác câu hỏi chọn một đáp án (Single Choice - Radio) vs chọn nhiều đáp án (Multiple Choice - Checkbox).
- Xử lý câu hỏi có đáp án kép như `D, E` hoặc `A, B, D` - tính điểm thi thử: chỉ được tính đúng khi người dùng chọn đúng và đủ tất cả các đáp án.
- Bộ đếm thời gian thi thử (Countdown Timer): tự động nộp bài khi hết giờ và ngăn người dùng sửa câu trả lời sau khi nộp bài.
- Khả năng khôi phục trạng thái mượt mà từ `localStorage` khi người dùng F5 / reload trang.
